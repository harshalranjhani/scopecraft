# ScopeCraft

A private proposal workspace for independent designers and developers. Turn a client brief into an editable scope, flag the unknowns, calculate your own price, and export a proposal.

Built from scratch for [Hacktoberfest 2026 Week 2: Side Hustle](https://dev.to/challenges/hacktoberfest-week2-2026-10-12), beginning October 13, 2026.

## Development

Requires Node.js 22.12 or newer.

```sh
npm install
npm run dev
```

Open http://localhost:5173. Open-model setup and demo instructions will be added as the app is built.

## Build milestones

1. App foundation and challenge brief.
2. Validated local open-model inference and deterministic pricing.
3. Responsive workspace, proposal editor, persistence, and export.
4. End-to-end verification and deployment.
